IMPORTANT
---------
The previous project used a 38-class model. Its class_names.json MUST NOT be
used with this 161-output model. A Keras model archive does not contain the
class folder names/order unless they were saved separately as an asset, and
this archive contains only metadata.json, config.json and model.weights.h5.

Install the exact class_names.json created during the same training run:

    python manage.py install_model_labels --json "C:\path\to\class_names.json"

Or, if you still have the exact dataset folder used for training:

    python manage.py install_model_labels --dataset "C:\path\to\dataset"

The command refuses any source that does not contain exactly 161 labels.
