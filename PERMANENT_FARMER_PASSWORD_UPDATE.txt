CROPCARE AI V4 — PERMANENT FARMER PASSWORD DISPLAY UPDATE
==========================================================

What changed
------------
- The password entered by the administrator during farmer registration is now
  available permanently in the "Recently registered farmers" table.
- The table includes Farmer, Username, Password, Location and Registered date.
- A Copy button is provided for each stored password.
- Access remains restricted to the logged-in Django superuser because the
  registration page is already superuser-only.

How it is stored
----------------
Django still stores its normal one-way login hash. The project additionally
stores an encrypted copy in FarmerProfile.encrypted_login_password so the main
administrator can retrieve the assigned password later. It is not stored as
plain text in the database.

Important
---------
- Keep DJANGO_SECRET_KEY private and unchanged. Existing encrypted passwords
  cannot be decrypted after that key is changed.
- Farmers registered before this update show:
  "Not stored (farmer registered before this update)".
- After upgrading an existing project, run:
    python manage.py migrate
